03 /The little details

Formatting that follows the project

JavaScript, TypeScript, and JSON use Biome. CSS and Svelte try Prettier first. Other filetypes use an available LSP formatter, excluding ts_ls and svelte. Project-local executables take precedence.

Language servers, when available

Biome, clangd, Pyright, Marksman, Svelte, ZLS, and TypeScript are enabled when their executables are found. Install the servers you need.

Keep the useful things

Persistent undo and backups in Neovim’s state directory. System clipboard integration. Smart-case search. Centered search results. No swap files.

Defaults, with exceptions

Two-space indentation and an 80-column guide. C and Python use four spaces; Go uses tabs. Markdown wraps text at 80 columns. Treesitter installs missing parsers on startup.

04 /Make yourself at home

Requires a Neovim version with vim.pack

$ git clone git@github.com:mrnugget/vimconfig.git ~/.vimconfig
$ ~/.vimconfig/setup.sh

The setup script links ~/.config/nvim to this configuration, backs up an existing directory, and installs missing dependencies when Homebrew is available. It then starts Neovim headlessly to install plugins and Treesitter parsers.
